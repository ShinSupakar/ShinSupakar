### 🌍 TerraWatch — Disaster Prediction & Response Platform

> *FastAPI · YOLOv8 · Real-ESRGAN · PyTorch · Docker · React*

🥈 **2nd Place — MLDA Deep Learning Week 2026, Security Track**

Production-style FastAPI backend for disaster prediction and response workflows. Features a **TorchScript aftershock forecaster** outputting 24-hour M4+ probability, a **multimodal CV damage assessment pipeline** (YOLOv8n + Real-ESRGAN), live USGS data polling, IoT sensor ingest, and a layman-summary LLM endpoint. Fully containerised with Docker for one-command deployment.

[View repo →](https://github.com/ShinSupakar/TerraWatch_Repo26)

### 🖼️ Deep Learning Image Restoration System *(FYP — Ongoing)*

> *PyTorch · GANs · CNNs · Full-Stack*

Built and evaluated 3 ML models on a 3,500-image dataset, achieving a **+5.14 dB PSNR gain** over the GAN baseline across 500 test evaluations. Resolved critical training bottlenecks, achieving 100% improvement success rate across all test cases. Deployed as a full-stack web app with real-time AI inference — ~74% parameter reduction without sacrificing reconstruction accuracy.

### 🧬 Clinical NLP Assistant

> *BioBERT · spaCy · BiLSTM-CRF · BiGRU · BERT · BART · Streamlit*

End-to-end clinical NLP pipeline converting unstructured notes into structured SOAP notes using 6 NER models and 2 RE models. **BioBERT** achieved the top F1-score of **~0.876** for drug/disease extraction. Integrated into a 3-tab Streamlit app for real-time entity recognition, relation extraction, and SOAP note generation.

### 💬 Sentiment Analysis — Three-Method Comparison

> *BERT · TF-IDF · scikit-learn · PyTorch*

Implemented and compared TF-IDF + Logistic Regression, frozen BERT embeddings, and fine-tuned BERT for binary sentiment classification. **Fine-tuned BERT** achieved **95.48% accuracy** and **97.36% F1-score**. Evaluated trade-offs between performance, computational cost, and contextual understanding — methodology directly applicable to RAG evaluation.

[View repo →](https://github.com/ShinSupakar/Sentiment-Analysis_AIDM)

### 😴 Real-Time Driver Drowsiness Detection

Real-time drowsiness detection system analysing live camera input for eye closure, head tilt, and yawning. Achieved **81.5% mAP50**, 83% precision, and 77.5% recall. Optimised inference by 30% via OpenCV Haar Cascade pre-filtering. Triggers audio alerts when fatigue indicators exceed thresholds.
